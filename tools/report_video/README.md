# 🎬 1분 보고용 영상 만들기

옹진2026여름 수업 사진과 아이들 그림으로 **정확히 60초짜리 보고용 MP4** 한 편을 만듭니다.

```
python3 make_report_video.py
```

---

## 구성 (60.0초)

| 구간 | 내용 |
|---|---|
| 타이틀 | 사업명 · **"옹진군 아이들의 여름방학"** · 섬 이름 · 기간(사진 날짜에서 자동) |
| 섬 카드 | 백령도 → 기관명·수업명을 폴더에서 읽어 자동으로 채움 |
| 가로 사진 | 꽉 채워 자르고 천천히 확대(켄번즈). 아래 왼쪽에 `섬 · 기관 / 수업명 · 날짜` 자막 |
| 세로·정사각 사진, 아이들 그림 | **자르지 않고** 흰 여백을 두른 액자로 통째로. 뒷배경은 같은 사진을 흐리게, 자막은 액자 아래 가운데 |
| 섬 카드 → 사진 | 영흥도 · 자월도 · 신도… **폴더에 있는 섬을 다 넣습니다** |
| 마무리 | 단체명 · 갤러리 주소 |

섬을 안 적으면 드라이브에 있는 섬 폴더를 모두 찾아 백령도 → 영흥도 → 자월도 → 신도 차례로 넣습니다.

장면은 0.55초 크로스페이드로 이어집니다.

**길이를 정하는 두 가지 길**

| | 쓰는 법 | 하는 일 |
|---|---|---|
| 길이를 못 박는다 | `--seconds 60` (기본) | 그 길이에 딱 맞게 사진 칸 수를 줄입니다. 한 컷 2.0~2.45초를 지키는 선에서 최대한 많이. |
| 사진을 다 넣는다 | `--cut 2.2` | 가진 사진을 **하나도 안 버리고** 다 넣고, 길이는 사진 수를 따라갑니다. |

옹진2026여름 전체(일정 25일 × 섬 6곳 × 기관 14곳 × 과정 64가지 = 140묶음)에서
묶음마다 한 장씩 뽑으면 140컷이고, `--cut 2.2` 로 **4분 8초**가 나옵니다.
1분 안에 140컷을 넣으려면 한 컷이 0.86초라 사진이 스쳐 지나갑니다.

- 온라인전용 마운트에서는 파일 열기가 막혀(EDEADLK) 사진을 한 장도 못 읽습니다.

  회사 egress 정책에 막혀(403) 사진을 받을 수 없습니다. 그래서 이 스크립트는 맥용입니다.

## 사진을 어디서 가져오나

**① 수업 모습 — 구글 드라이브 `옹진2026여름`**

```
옹진2026여름/
└── 20260821/            ← 날짜
    └── 백령도/           ← 섬
        └── 백령종합사회복지관/    ← 기관
            └── 창의공예/          ← 수업명
                ├── 사진1.jpg
                └── [강사] …_사진_20260821/   ← 이런 하위폴더가 남아 있어도 같이 읽습니다
```

폴더를 못 찾으면 `~/mnt/*`, `~/Library/CloudStorage/GoogleDrive-*/...` 를 차례로 훑고,
그래도 없으면 `--base` 로 알려주면 됩니다.

같은 수업 사진만 몰리지 않도록 **(날짜, 기관, 수업) 묶음을 돌아가며** 고릅니다.

**② 아이들 그림 — 갤러리와 같은 Firebase (`submissions`)**

갤러리가 쓰는 것과 같은 곳이고 읽기가 공개라 따로 로그인할 게 없습니다.
`class_code` 에 `백령` / `영흥` 이 들어간 작품만 골라 받습니다.
받은 그림은 `.report_video_cache/artwork/` 에 저장해 두고 다음 실행 때 다시 씁니다.

안 쓰려면 `--no-firebase` — 드라이브 사진만으로 만듭니다.

반코드로 콕 집어 넣고 싶으면 갤러리 주소의 `?class=` 값을 쓰면 됩니다.
예: `izzy-lee.github.io/artclasshub-gallery/?class=F4MD28` → 백령종합사회복지관,
`?class=KHGUKC` → 영흥도 다함께돌봄센터. 이 작품들은 `--manifest` 에 `art` 로 적어
**찍힌 날짜 자리에** 끼워 넣습니다(그날 수업 사진 바로 뒤).

> `created_at` 은 UTC라 한국 시간(+9)으로 바꿔 날짜를 잡아야 합니다.
> 예: `2026-07-27T15:45Z` → 7월 28일.

## 옵션

```bash
# 폴더를 직접 지정
python3 make_report_video.py --base ~/mnt/옹진2026여름

# 섬 고르기 (안 적으면 폴더에 있는 섬을 다 넣습니다)
python3 make_report_video.py --islands 백령도 영흥도

# 쓸 사진을 직접 골라 차례까지 정하고 싶을 때
python3 make_report_video.py --manifest 사진목록.tsv --photo-dir ./사진

# 제목 바꾸기
python3 make_report_video.py --title "옹진군 아이들의 여름방학"

# 90초 버전
python3 make_report_video.py --seconds 90

# 가진 사진을 다 넣기 (길이는 사진 수를 따라감)
python3 make_report_video.py --cut 2.2

# 배경음악 넣기 (넣으면 앞 1.5초 페이드인 · 뒤 2.5초 페이드아웃)
python3 make_report_video.py --audio ~/Music/bgm.m4a

# 사진 없이 구성만 먼저 확인
python3 make_report_video.py --demo

# 문구 바꾸기
python3 make_report_video.py --program "2026 옹진군 여름방학중 초등돌봄 교실" \
                             --org-name "아트에이블" \
                             --footer "온라인 갤러리  izzy-lee.github.io/artclasshub"
```

| 옵션 | 기본값 | 설명 |
|---|---|---|
| `--base` | 자동 탐색 | `옹진2026여름` 폴더 경로 |
| `--islands` | 폴더에 있는 섬 전부 | 넣을 섬 |
| `--title` | `옹진군 아이들의 여름방학` | 큰 제목 |
| `--manifest` | 없음 | 쓸 사진을 직접 정한 TSV 목록 |
| `--photo-dir` | 목록 파일 옆 | `--manifest` 사진이 든 폴더 |
| `--out` | `옹진2026여름_보고영상_60초.mp4` | 결과 파일 |
| `--audio` | 없음(무음) | 배경음악 |
| `--no-firebase` | 끔 | 아이들 그림 안 받기 |
| `--art-max` | `24` | 받아올 그림 최대 장수 |
| `--seconds` | `60` | 완성본 길이(초). 여기 맞춰 사진 칸 수를 줄입니다 |
| `--cut` | 없음 | 한 컷 길이(초)를 정하고 사진을 다 넣습니다. 길이는 따라옴 |
| `--crf` | `19` | 화질(낮을수록 좋고 용량 큼, 18~23) |
| `--demo` | 끔 | 자리표시 영상만 |

## 결과

1920×1080 / 30fps / H.264 / `+faststart` — 카톡·메일·유튜브·발표 자료에 그대로 올라갑니다.
사진 30장(60초)이면 **약 1분 30초**, 140장(4분 8초)이면 **약 7분** 걸립니다.
용량은 60초 30MB, 4분 100MB 안팎입니다.

## 손보고 싶을 때

`make_report_video.py` 맨 위 상수만 바꾸면 됩니다.

```python
W, H, FPS = 1920, 1080, 30
TOTAL = 60.0     # 완성본 길이(초)
XF    = 0.55     # 장면 사이 크로스페이드
ZMAX  = 1.13     # 켄번즈 최대 확대율
INK / PAPER / SEA / SUN / MINT    # 색
```

`TOTAL` 만 바꾸면 사진 칸 수를 다시 계산해 그 길이에 딱 맞춥니다(30초·90초 버전도 바로 됩니다).
`FRAME_BELOW`(기본 1.25)는 가로세로비가 이보다 작은 사진을 액자로 보여주는 기준입니다.

### 사진 목록(`--manifest`) 형식

탭으로 나눈 다섯 칸. 적은 차례 그대로 영상에 들어갑니다.

```
파일이름(또는 경로)⇥섬⇥기관⇥수업명⇥날짜(YYYYMMDD)⇥종류⇥학생이름
사진1.jpg	백령도	백령종합사회복지관	창의공예	20260821
사진2.jpg	영흥도	옹진군가족센터	제과제빵	20260819
그림1.jpg	백령도	백령종합사회복지관	우리 그림	20260818	art	김지원
```

뒤 두 칸은 없어도 됩니다(없으면 수업 사진으로 봅니다).
`art` 로 적으면 아이들 그림 — 잘리지 않게 액자로 넣고, 자막 아랫줄에 `학생이름 그림` 이 붙습니다.
섬 안에서 **날짜순**으로 적으면 그림이 그날 수업 사진 바로 뒤에 놓입니다.
