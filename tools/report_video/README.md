# 🎬 1분 보고용 영상 만들기

옹진2026여름 수업 사진과 아이들 그림으로 **정확히 60초짜리 보고용 MP4** 한 편을 만듭니다.

```
python3 make_report_video.py
```

---

## 구성 (60.0초)

| 구간 | 내용 |
|---|---|
| 타이틀 | 사업명 · **"옹진군 아이들의 여름방학"** · 섬 이름 · 기간(사진 날짜에서 자동) |
| 섬 카드 | 백령도 → 기관명·수업명을 폴더에서 읽어 자동으로 채움 |
| 가로 사진 | 꽉 채워 자르고 천천히 확대(켄번즈). 아래 왼쪽에 `섬 · 기관 / 수업명 · 날짜` 자막 |
| 세로·정사각 사진, 아이들 그림 | **자르지 않고** 흰 여백을 두른 액자로 통째로. 뒷배경은 같은 사진을 흐리게, 자막은 액자 아래 가운데 |
| 섬 카드 → 사진 | 영흥도 · 자월도 · 신도… **폴더에 있는 섬을 다 넣습니다** |
| 마무리 | 단체명 · 갤러리 주소 |

섬을 안 적으면 드라이브에 있는 섬 폴더를 모두 찾아 백령도 → 영흥도 → 자월도 → 신도 차례로 넣습니다.

장면은 0.55초 크로스페이드로 이어집니다.

**길이를 정하는 두 가지 길**

| | 쓰는 법 | 하는 일 |
|---|---|---|
| 길이를 못 박는다 | `--seconds 60` (기본) | 그 길이에 딱 맞게 사진 칸 수를 줄입니다. 한 컷 2.0~2.45초를 지키는 선에서 최대한 많이. |
| 사진을 다 넣는다 | `--cut 2.2` | 가진 사진을 **하나도 안 버리고** 다 넣고, 길이는 사진 수를 따라갑니다. |

옹진2026여름 전체(일정 25일 × 섬 6곳 × 기관 14곳 × 과정 64가지 = 140묶음)에서
묶음마다 한 장씩 뽑으면 140컷이고, `--cut 2.2` 로 **4분 8초**가 나옵니다.
1분 안에 140컷을 넣으려면 한 컷이 0.86초라 사진이 스쳐 지나갑니다.

## 사진을 어디서 가져오나

**① 수업 모습 — 구글 드라이브 `옹진2026여름`**

```
옹진2026여름/
└── 20260821/            ← 날짜
    └── 백령도/           ← 섬
        └── 백령종합사회복지관/    ← 기관
            └── 창의공예/          ← 수업명
                ├── 사진1.jpg
                └── [강사] …_사진_20260821/   ← 이런 하위폴더가 남아 있어도 같이 읽습니다
```

폴더를 못 찾으면 `~/mnt/*`, `~/Library/CloudStorage/GoogleDrive-*/...` 를 차례로 훑고,
그래도 없으면 `--base` 로 알려주면 됩니다.

같은 수업 사진만 몰리지 않도록 **(날짜, 기관, 수업) 묶음을 돌아가며** 고릅니다.

**② 아이들 그림 — 갤러리와 같은 Firebase (`submissions`)**

갤러리가 쓰는 것과 같은 곳이고 읽기가 공개라 따로 로그인할 게 없습니다.
`class_code` 에 `백령` / `영흥` 이 들어간 작품만 골라 받습니다.
받은 그림은 `.report_video_cache/artwork/` 에 저장해 두고 다음 실행 때 다시 씁니다.

안 쓰려면 `--no-firebase` — 드라이브 사진만으로 만듭니다.

반코드로 콕 집어 넣고 싶으면 갤러리 주소의 `?class=` 값을 쓰면 됩니다.
예: `izzy-lee.github.io/artclasshub-gallery/?class=F4MD28` → 백령종합사회복지관,
`?class=KHGUKC` → 영흥도 다함께돌봄센터. 이 작품들은 `--manifest` 에 `art` 로 적어
**찍힌 날짜 자리에** 끼워 넣습니다(그날 수업 사진 바로 뒤).

> `created_at` 은 UTC라 한국 시간(+9)으로 바꿔 날짜를 잡아야 합니다.
> 예: `2026-07-27T15:45Z` → 7월 28일.

## 옵션

```bash
# 폴더를 직접 지정
python3 make_report_video.py --base ~/mnt/옹진2026여름

# 섬 고르기 (안 적으면 폴더에 있는 섬을 다 넣습니다)
python3 make_report_video.py --islands 백령도 영흥도

# 쓸 사진을 직접 골라 차례까지 정하고 싶을 때
python3 make_report_video.py --manifest 사진목록.tsv --photo-dir ./사진

# 제목 바꾸기
python3 make_report_video.py --title "옹진군 아이들의 여름방학"

# 90초 버전
python3 make_report_video.py --seconds 90

# 가진 사진을 다 넣기 (길이는 사진 수를 따라감)
python3 make_report_video.py --cut 2.2

# 배경음악 넣기 (넣으면 앞 1.5초 페이드인 · 뒤 2.5초 페이드아웃)
python3 make_report_video.py --audio ~/Music/bgm.m4a

# 음악이 없으면 직접 지어서 쓴다 (영상 길이에 딱 맞춰 나옴)
python3 make_music.py --seconds 272.9 --out bgm.wav
python3 make_report_video.py --cut 2.2 --audio bgm.wav

# 사진 없이 구성만 먼저 확인
python3 make_report_video.py --demo

# 문구 바꾸기
python3 make_report_video.py --program "2026 옹진군 여름방학중 초등돌봄 교실" \
                             --org-name "아트에이블" \
                             --footer "온라인 갤러리  izzy-lee.github.io/artclasshub"
```

| 옵션 | 기본값 | 설명 |
|---|---|---|
| `--base` | 자동 탐색 | `옹진2026여름` 폴더 경로 |
| `--islands` | 폴더에 있는 섬 전부 | 넣을 섬 |
| `--title` | `옹진군 아이들의 여름방학` | 큰 제목 |
| `--manifest` | 없음 | 쓸 사진을 직접 정한 TSV 목록 |
| `--photo-dir` | 목록 파일 옆 | `--manifest` 사진이 든 폴더 |
| `--out` | `옹진2026여름_보고영상_60초.mp4` | 결과 파일 |
| `--audio` | 없음(무음) | 배경음악 |
| `--no-firebase` | 끔 | 아이들 그림 안 받기 |
| `--art-max` | `24` | 받아올 그림 최대 장수 |
| `--seconds` | `60` | 완성본 길이(초). 여기 맞춰 사진 칸 수를 줄입니다 |
| `--cut` | 없음 | 한 컷 길이(초)를 정하고 사진을 다 넣습니다. 길이는 따라옴 |
| `--crf` | `19` | 화질(낮을수록 좋고 용량 큼, 18~23) |
| `--demo` | 끔 | 자리표시 영상만 |

## 손보고 싶을 때

`make_report_video.py` 맨 위 상수만 바꾸면 됩니다.

```python
W, H, FPS = 1920, 1080, 30
TOTAL = 60.0     # 완성본 길이(초)
XF    = 0.55     # 장면 사이 크로스페이드
ZMAX  = 1.13     # 켄번즈 최대 확대율
INK / PAPER / SEA / SUN / MINT    # 색
```

`TOTAL` 만 바꾸면 사진 칸 수를 다시 계산해 그 길이에 딱 맞춥니다(30초·90초 버전도 바로 됩니다).
`FRAME_BELOW`(기본 1.25)는 가로세로비가 이보다 작은 사진을 액자로 보여주는 기준입니다.

### 사진 목록(`--manifest`) 형식

탭으로 나눈 다섯 칸. 적은 차례 그대로 영상에 들어갑니다.

```
파일이름(또는 경로)⇥섬⇥기관⇥수업명⇥날짜(YYYYMMDD)⇥종류⇥학생이름
사진1.jpg	백령도	백령종합사회복지관	창의공예	20260821
사진2.jpg	영흥도	옹진군가족센터	제과제빵	20260819
그림1.jpg	백령도	백령종합사회복지관	우리 그림	20260818	art	김지원
```

뒤 두 칸은 없어도 됩니다(없으면 수업 사진으로 봅니다).
`art` 로 적으면 아이들 그림 — 잘리지 않게 액자로 넣고, 자막 아랫줄에 `학생이름 그림` 이 붙습니다.
섬 안에서 **날짜순**으로 적으면 그림이 그날 수업 사진 바로 뒤에 놓입니다.

## 🎹 배경음악 직접 짓기 — `make_music.py`

남의 곡을 쓰면 저작권이 걸리니, 쓸 곡을 그 자리에서 지어 씁니다.

```bash
python3 make_music.py --seconds 272.9 --out bgm.wav     # 영상 길이를 그대로 넣으면 됨
python3 make_music.py --seconds 272.9 --out bgm.wav --seed 7   # 가락이 마음에 안 들면 숫자만 바꾸기
```

**곡 구성** — 발랄한 피아노 소품(고전풍 소나티네). 144마디를 영상 길이에 맞춰
빠르기로 늘이고 줄이므로, 몇 분짜리 영상이든 딱 맞게 끝납니다.

| 부분 | 마디 | 조 | 느낌 |
|---|---|---|---|
| 도입 | 4 | 다장조 | 조용히 펼친 화음으로 문 열기 |
| A | 32 | 다장조 | 주제 — 8분음표로 통통 튀는 가락 |
| B | 16 | 사장조 | 한 칸 밝게 |
| A′ | 16 | 다장조 | 주제 되돌아오기 |
| C | 32 | 바장조 | 노래하듯 느긋하게 |
| A″ | 32 | 다장조 | 가장 환하게(첫 박 옥타브) |
| 마무리 | 12 | 다장조 | Ⅳ–Ⅴ–Ⅰ 로 천천히 맺기 |

**어떻게 만드나**

1. 마디마다 화성을 정하고 — 음계 위에 한 칸 띄어 쌓아 조성이 저절로 맞습니다
2. 박마다 코드음을 짚고 그 사이를 음계로 이어 가락을 만듭니다
   (센박은 반드시 화음의 음, 여린박은 지나가는 음 → 어긋난 소리가 안 납니다)
3. 왼손은 알베르티 베이스·아르페지오·화음으로 받칩니다
4. 피아노 소리를 배음 합성으로 직접 만듭니다 — 진짜 줄처럼 배음이 정수배보다
   조금씩 높고(inharmonicity), 높은 배음이 먼저 사그라들고, 세게 칠수록 밝고,
   두 줄이 미세하게 어긋나 넘실댑니다. 망치가 줄을 때리는 '탁' 소리도 넣었습니다
5. 잔향을 입히고, 2.5kHz 위를 살짝 올려 또랑또랑하게 다듬습니다

`--seed` 숫자만 바꾸면 화성과 구성은 그대로 두고 가락만 다시 짭니다.

만든 음악을 영상에 붙이려면:

```bash
ffmpeg -i 영상.mp4 -i bgm.wav -map 0:v:0 -map 1:a:0 \
       -c:v copy -c:a aac -b:a 192k -shortest -movflags +faststart 완성.mp4
```

## 📖 그림책 책장 넘기는 영상 — `make_book_video.py`

갤러리에 올라온 아이들 그림책을 한 권씩 표지부터 넘겨 보여 주는 영상입니다.

```bash
python3 make_book_video.py --manifest 책목록.tsv --page-dir ./pages --out 그림책.mp4
python3 make_book_video.py ... --hold 1.6 --turn 0.55 --gap 0.45
```

**표지 파일은 앞·뒤로 나눕니다** — `000` 은 좌우가 붙은 표지 펼침면입니다.
오른쪽 반쪽이 **앞표지**(제목), 왼쪽 반쪽이 **뒷표지**(만든이)입니다.

| 차례 | 화면 |
|---|---|
| ① 앞표지 | 닫힌 책이 가운데 (책등 두께가 왼쪽에 보임) |
| ② 편다 | 앞표지가 왼쪽으로 돌아가며 첫 속장이 드러남. 책이 가운데로 넓어짐 |
| ③ 속장 | `001`~`003` 을 한 장씩 넘김 |
| ④ 덮는다 | 마지막 장이 넘어가며 뒷표지가 위로 옴 |
| ⑤ 뒷표지 | 닫힌 책이 가운데 (책등 두께가 오른쪽에 보임) |

**넘김이 어떻게 되나** — 속장도 진짜 책처럼 가운데 책등을 축으로 오른쪽 장이 왼쪽으로 돌아갑니다.

| 각도 | 화면 |
|---|---|
| 0° | 지금 펼침면 그대로 |
| 0°→90° | 오른쪽 장이 책등 쪽으로 좁아지며 접힘. 그 아래에서 다음 펼침면의 오른쪽 쪽이 드러남 |
| 90°→180° | 넘어간 장의 **뒷면**(= 다음 펼침면의 왼쪽 쪽)이 책등에서 왼쪽으로 펼쳐짐 |

장이 접히며 책등 쪽이 어두워지고, 넘어가는 장이 아래 쪽에 그림자를 드리웁니다.
들린 쪽은 위아래로 살짝 커져(원근) 종이가 일어선 느낌이 납니다.

**규칙**

- 목록 파일에 적은 **순서 그대로** 이어 붙입니다
- 네 번째 칸에 반 이름을 적어 두면, 반이 바뀔 때마다 **반 이름 간지**가 끼어 듭니다
- 모든 쪽이 채워진 책은 **표지부터** 끝까지 넘깁니다
- 거의 흰 종이인 **빈 쪽은 빼고**, 그림이 있는 쪽만 넣습니다
- **양장본**으로 그립니다 — 표지 보드가 종이보다 조금 크게 둘리고, 쌓인 종이의
  마구리와 그림자가 보이며, 펼친 쪽은 책등 쪽으로 눕듯 휩니다
- 보드 색은 **표지 그림에서 뽑아** 파스텔로 눅입니다. 표지가 흰 책도 바탕에
  묻히지 않도록 밝기를 눌러 줍니다

### 어떤 반을 넣을지

목록 파일에 적은 책만 들어갑니다. 반 이름은 Firestore `classes` 컬렉션에 있습니다.

| 반코드 | 반 이름 |
|---|---|
| `F4MD28` | 백령종합사회복지관 |
| `KHGUKC` | 영흥도 다함께돌봄센터 |
| `S753Z4` | 옹진군가족센터 |
| `6APJVY` | 온마을학교 2기 |
| `F7DRCX` | 부일초 창의미술 |
| `BPGJXL` | 임학중 빅피쳐 |
| `FZHBPA` | 주말학교2026 |
| `TEYNFZ` | 논곡초 한국어학급 |

옹진 사업 영상에는 위의 **백령·영흥·옹진 세 반**만, **백령 → 영흥 → 옹진** 순서로 넣습니다.
목록 파일을 그 순서로 적어 두고 네 번째 칸에 반 이름을 넣으면 간지가 알아서 들어갑니다.

| 옵션 | 기본값 | 설명 |
|---|---|---|
| `--manifest` | 없음(필수) | `제목 ⇥ 학생 ⇥ 쪽파일들(쉼표) ⇥ 반 이름(선택)` |
| `--page-dir` | 목록 파일 옆 | 쪽 그림이 든 폴더 |
| `--hold` | `1.5` | 속장 한 펼침면을 보여 주는 시간(초) |
| `--cover-hold` | `1.2` | 앞표지를 보여 주는 시간(초) |
| `--back-hold` | `0.9` | 뒷표지를 보여 주는 시간(초) |
| `--turn` | `0.55` | 속장 넘기는 시간(초) |
| `--open` | `0.7` | 책을 펴고 덮는 시간(초) |
| `--gap` | `0.45` | 책과 책 사이 넘어가는 시간(초) |
| `--section-hold` | `1.8` | 반이 바뀔 때 끼우는 간지를 보여 주는 시간(초). `0`이면 안 넣습니다 |
| `--title` | `우리가 만든 그림책` | 첫 화면 제목 |
| `--bg` | `#FFFFFF,#D6F4FD` | 책이 놓인 바닥색. `#RRGGBB` 하나면 단색, 쉼표로 두 개를 주면 왼→오 가로 그라데이션. 어두운 색을 주면 글자도 밝게 따라갑니다 |
| `--bg-gamma` | `1.5` | 그라데이션이 번지는 모양. 1보다 크면 왼쪽 색이 더 오래 머뭅니다 |

길이는 권마다 `gap + cover-hold + open + 속장수×hold + (속장수-1)×turn + open + back-hold` 입니다.
4쪽(표지 1 + 속장 3)짜리 18권이면 약 3분.

### 그림책이 드라이브 어디에 있나

`STORYBOOK_SHEET_ID` 시트가 명부(`시각·bookId·제목·학생·반·페이지수·표지`)이고,
쪽 그림은 `storybook_<bookId>` 폴더에 `000.jpg`~`003.jpg` 로 들어 있습니다.

> 그림책 웹앱(`script.google.com`)은 Claude Code 웹 세션에서 egress 정책에 막힙니다.
> 그래서 웹앱 대신 **드라이브 폴더를 바로 읽습니다.** 맥에서는 웹앱을 써도 됩니다.

## ☀️ 여름 분위기 배경음악 — `make_summer_bgm.py`

```bash
python3 make_summer_bgm.py --seconds 158 --out 여름날.mp3            # 피아노 한 대(기본)
python3 make_summer_bgm.py --seconds 158 --out 여름날.mp3 --seed 5   # 가락만 다시
python3 make_summer_bgm.py --seconds 158 --out 여름날.mp3 --ensemble # 현·글로켄 더하기
```

> **기본은 피아노 한 대입니다.** 현 패드는 어긋나게 겹친 톱니가 웅웅거리고,
> 글로켄슈필은 정수배가 아닌 배음이라 금속성이 돌아 으스스하게 들립니다.
> 맑은 소리를 원하면 그대로 두세요. 두툼하게 깔고 싶을 때만 `--ensemble`.

밝고 조금 그리운 여름 소품입니다. 히사이시 조 풍 애니메이션 스코어의 **분위기**를
노린 창작곡이고, 특정 곡의 가락이나 진행을 옮겨 오지 않습니다.

**뼈대** — 78마디, ♩≈118, 다장조

| 부분 | 마디 | 하는 일 |
|---|---|---|
| 들어가기 | 6 | 왼손 아르페지오만 조용히 |
| 주제 A | 16 | 오른손 가락 들어옴 |
| 주제 A′ | 16 | 조금 세게 |
| 다리 | 16 | 늘여 부르는 가락 |
| 주제 A″ | 16 | 가장 환하게 |
| 마무리 | 8 | 얇아지며 서서히 느려짐 |

**왼손**은 낮은 음을 하나 짚고 화음을 또르르 굴립니다(`베이스 · 3음 · 5음 · 8음`을
8분음표로). 화음은 3화음만 써서 서로 부딪히지 않습니다 — 7음·9음의 색은
오른손 가락이 지나가며 냅니다.

**화성** — 이른바 캐논 진행 `Ⅰ Ⅴ/7 ⅵ ⅲ/5 Ⅳ Ⅰ/3 ⅱ Ⅴ`.
베이스가 **도–시–라–솔–파–미–레–솔** 로 걸어 내려가는 그 소리입니다.
화음은 7음까지 쌓아(maj7·m7) 말갛기보다 조금 물기 있게 들립니다.

**편성** — 소리를 전부 직접 합성합니다.

| 악기 | 만드는 법 | 기본 |
|---|---|---|
| 피아노 | `make_music.py` 의 배음 합성을 그대로 씀 | ✅ |
| 현 패드 | 톱니에 가까운 배음을 셋으로 어긋나게 겹치고 저역통과 | `--ensemble` |
| 글로켄슈필 | 정수배가 아닌 배음(1 : 2.76 : 5.4 : 8.9) | `--ensemble` |
| 뜯는 베이스 | 카플러스-스트롱 — 잡음을 줄에 가둬 튕김 | `--ensemble` |

울림(잔향)은 옅게(17%)만 겁니다. 짙게 걸면 피아노가 뿌예집니다.

`--seconds` 에 영상 길이를 그대로 넣으면 마디 수는 두고 빠르기로 맞춥니다.
끝 16박은 서서히 느려지고, 2.2초에 걸쳐 잦아듭니다. 결과는 MP3(기본 256k)입니다.
